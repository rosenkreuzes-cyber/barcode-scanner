QuickScan DB + PaddleOCR / 完全版 2026.11.26-r1
================================================

【構成】
  index.html       PC・スマホ共通の画面と操作
  styles.css       画面用CSS（インターネット接続不要）
  app.py           OCRサーバー（PaddleOCR）
  manifest.json    ブラウザ用アプリ設定
  requirements.txt Pythonの依存パッケージ

【インストール】
  1. ZIPを展開し、すべて同じフォルダーに配置してください。
  2. Python 3.10～3.12を推奨します。
  3. Windowsでコマンドプロンプトを開き、展開フォルダーへ移動します。
       cd C:\QuickScanPaddleOCR
       py -3.11 -m venv .venv
       .venv\Scripts\activate
       python -m pip install --upgrade pip
       pip install -r requirements.txt
  4. サーバーを起動します。
       python app.py
  5. PCでは http://127.0.0.1:5000/ へアクセスしてください。

【スマートフォン】
  PCとスマホを同じWi-Fiに接続し、PCのローカルIPアドレスを確認してください。
  例: http://192.168.1.20:5000/
  画面上部に「画面版 2026.11.26-r1」が表示されているか確認してください。
  PCとスマホでURLのポート番号やサーバーが同じか確認してください。
  古いショートカットやホーム画面アイコンを使う場合は再読み込みしてください。
  WindowsファイアウォールでPythonの通信許可が必要な場合があります。
  http://PCのIP:5000/index.html でも同じ画面が表示されます。

【カメラとOCR】
  画面内「撮影・読取」でブラウザカメラが使用できない場合、
  「端末標準カメラで撮影」を使用してください。
  多くのスマホブラウザはHTTPのLAN接続でgetUserMediaを制限します。
  ライブカメラは適切なHTTPS配信が必要です。
  OCR自体はPCで動作し、文字列から製品型式・シリアルNo・Verを推定します。
  初回起動時はOCRモデルを取得するためインターネット接続が必要です。
  読取結果は必ず確認してください。

【登録と印刷】
  電源ユニット → CPU → ベースユニット → LIO-04 → 各種機器追加 → 印刷
  LIO-04画面の「＋ LIO-04の追加」でLIO-04を増やせます。
  各種機器追加画面の「＋ 機器追加」で追加機器を増やせます。
  各種機器の「機器名称（任意）」は備考とは別に入力できます。
  製品型式が空欄なら、印刷・CSVの「機器名称」も空欄です。
  機器名称が未入力の各種機器は、製品型式があっても名称は空欄です。
  LIO-04の機器名称は「LIO-04」です（「追加1」などの連番なし）。

【保存・復元】
  基本情報と機器情報は、操作しているブラウザに自動保存されます。
  ホームへ戻る・ブラウザ再読込後も、同じ号機の情報は復元されます。
  号機Noを変更すると機器情報のみ消去し、基本情報は保持します。
  共有端末では「端末の保存データを消去」を使ってください。
  ※ブラウザのプライベートモードや保存禁止設定では自動保存されない場合があります。
  ※PCとスマホの間で自動同期はしません。移動にはCSVの保存・読込をご利用ください。

  CSVは「機器名称」の表示ルールを印刷と統一し、6・7列目に
  登録種別・各種機器名称の入力値を追加しています（旧5列CSVは読込可能）。
  これらの列は、型式未入力の追加機器や機器名称の編集状態を復元するために必要です。
  CSVを保存してもブラウザ側の自動保存内容は消去されません。

【注意】
  この簡易サーバーは認証やHTTPSを設定していません。
  公開インターネットから直接アクセスできる状態にしないでください。
  index.htmlをファイルとして開く(file://)場合、OCR通信はできません。
  必ずpython app.pyで起動したURLを使用してください。
